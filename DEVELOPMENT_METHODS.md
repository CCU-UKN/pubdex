# Development-method disclosure

This repository’s initial public baseline was prepared with assistance
from generative AI development tools.

## Scope of use

The tools assisted with:

- reviewing and reorganising existing code;
- providing ideas and editing implementation changes;
- creating and revising tests;
- suggesting and editing documentation;
- investigating defects and release-readiness issues;
- checking consistency, public-safety constraints and acceptance evidence.

The private prototype that forms the starting point of this repository
predates the funded work. This disclosure concerns the preparation of
the curated public baseline and does not claim that the entire
prototype was generated through these tools.

## Tools and provenance

Tools used:

- OpenAI Codex (multiple model versions)
- Anthropic Claude Code (multiple model versions)

The exact model and version used for each interaction were not
consistently recorded.

The initial public repository is deliberately published as one curated
root commit, so tool-assisted and manually written changes are not
separated into earlier public commits. This document provides a
repository-level provenance summary for that baseline.

A complete prompt-and-output log was not maintained and is not available
for publication. The scope above therefore provides a repository-level
account of how the tools affected this baseline. The maintainer reviewed
and integrated the resulting changes and verified them using the
documented test and acceptance procedures.

## Human responsibility and review

The maintainer determined the project scope and design, reviewed the
resulting changes, and remains responsible for their correctness,
licensing and maintenance. Suggestions were not accepted solely because
they were generated by a tool.

The candidate was reviewed through source inspection, automated tests,
database integration tests, migration checks, synthetic acceptance
demonstrations and public-safety checks. The applicable verification
commands and expected results are documented in `TASK_1A.md`.

No suggestion from these tools was accepted without human review and
integration, and no tool output is being presented as an independently
eligible funded result. The delivered result is the reviewed and
integrated repository maintained by the project author.

## Future contributions

Future contributions that use generative-AI tools in a substantive way
should identify the tool and model, describe how it affected the
contribution, and provide a summary of the relevant interactions and
resulting output, or an equivalent provenance record.
